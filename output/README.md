# output

Successful accounts and run results are saved here by the tool.

Files:
- browser_accounts.txt - IDs saved by Browser mode (uid|password|cookies)
- success.txt - IDs saved by HTTP mode (uid|password|cookies)
- cookies_output.txt - Mode 5 Cookie Extract output
- posted_reviews.txt - record of posted reviews
- used_dp_pics.txt - record of DP pictures already used

WARNING: after you run the tool these files contain real account
cookies and passwords. NEVER commit or push them with real data.
If git shows them as modified, do NOT `git add` them.
